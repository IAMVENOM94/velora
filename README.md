# Velora

Dark premium dating app prototype. Stage 1 contains a complete interactive Jetpack Compose UI on local mock data.

## Run

1. Set `sdk.dir` in `local.properties`.
2. Run `./gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`).
3. Install `app/build/outputs/apk/debug/app-debug.apk`.

The product name is replaceable through `app/src/main/res/values/strings.xml`.
